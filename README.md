# WanderLust

WanderLust is a travel booking platform designed to simplify travel planning 
and provide users with an intuitive interface to explore destinations, book stays,
and connect with mentors for guidance. This app integrates Mapbox for interactive 
maps and offers features like reviews, mentors, and detailed location information.

---

## 🚀 Features

- **Explore Destinations**: Browse travel destinations with high-quality images and descriptions.
- **Interactive Map Integration**: Powered by Mapbox, view locations on a dynamic map with markers and popups.
- **Mentor Guidance**: Contact mentors for personalized travel guidance.
- **Booking System**: Easy checkout for travel stays with location and price details.
- **Review System**: Leave and view reviews for locations to make informed decisions.


---

## 🛠️ Tech Stack

- **Frontend**: React, TailwindCSS
- **Maps API**: Mapbox
- **Backend**: Node.js (future scope for API integration)
- **Toast Notifications**: `react-toastify`
- **Routing**: React Router
